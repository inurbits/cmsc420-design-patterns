behavioral/ — Behavioral — object interaction
📄command.py Turn a request into a stand-alone object so it can be queued, logged, or undone. B-01 📄iterator.py Give a collection a uniform way to be walked through, without exposing its internals. B-02 📄memento.py Capture and restore an object's internal state without exposing that state to the outside. B-03 📄null_object.py Replace 'if not None' checks with a real object that simply does nothing. B-04 📄observer.py Let interested objects subscribe to changes, instead of hard-wiring every dependent call. B-05 📄state.py Let an object change its behavior by swapping the state object it delegates to. B-06 📄strategy.py Make an algorithm swappable at runtime instead of branching on a mode flag. B-07 📄template_method.py Fix the shape of an algorithm in a base class, letting subclasses fill in only the steps that vary. B-08 📄visitor.py Add new operations over a fixed set of classes without touching those classes again. B-09
